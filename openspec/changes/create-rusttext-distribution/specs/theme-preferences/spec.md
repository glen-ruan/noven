## ADDED Requirements

### Requirement: RustText Jade built-in theme

The built-in catalog SHALL include a stable `RustText Jade` light theme after the original six compatibility themes. It SHALL provide a low-glare neutral surface palette with jade/teal active colors and Chinese-capable Noto font contributions for editor, rendered, and code planes.

#### Scenario: RustText Jade is selectable and persistent

- **WHEN** the Preferences panel enumerates themes
- **THEN** RustText Jade appears as a built-in theme and can be selected and persisted by name
